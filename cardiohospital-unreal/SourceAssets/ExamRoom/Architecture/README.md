# Gate 2 — Exam Room 3 architectural shell

Measured production architecture. Temporary materials only. Run on the RTX 4090.

```text
blender --background --python build_exam_room_architecture.py
```

Writes `generated/` next to this script: `.blend`, FBX, GLB, three 2560×1440 stills, manifest.

Layout numbers come from `../Gate1/exam_room_greybox_layout.py` (v2 + west-wall sink).
Do not Hunyuan this folder.
