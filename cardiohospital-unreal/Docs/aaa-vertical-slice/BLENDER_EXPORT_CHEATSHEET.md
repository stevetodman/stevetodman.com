# Blender → UE 5.8 cheatsheet (props)

## Once per file
1. Metric units, scale 1.0 (meters)
2. Origin at floor center
3. Ctrl-A Apply All Transforms

## Export FBX
- Scale 1.0
- -Y Forward, Z Up
- Apply Transform ON
- Smoothing: Face
- Apply Modifiers ON
- Path Mode: Copy

## Import Unreal
- Convert Scene ON
- Uniform Scale 1.0
- Generate collision ON (or custom UCX)
- Put mesh in Content/Environments/TeamRoom or ExamRoom3
