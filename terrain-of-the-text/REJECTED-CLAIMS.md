# Rejected Claims

This file is an immunity system against plausible-sounding assertions that have already failed review.

A rejected claim must not return to the atlas unless new evidence is documented in an approved round.

## Jewish travelers normally avoided Samaria

**Status:** rejected as a general rule.

**Reason:** the evidence does not support presenting avoidance of Samaria as the normal Jewish travel pattern. Josephus records Galileans using the Samaritan route for pilgrimage travel. Jewish-Samaritan hostility is real, but that does not justify turning route avoidance into a universal or normal rule.

**Implication for John 4:** do not explain John 4:4 by saying Jesus chose an unusual road that most Jews would not take. The phrase `had to pass through Samaria` may invite narrative/theological interpretation, but geography alone does not establish that reading.

## Artificial 50/50 weights for disputed biblical sites

**Status:** rejected unless a source provides an actual quantitative basis.

**Reason:** equal numerical weights create false precision. Present serious candidates and their evidence without invented probabilities.

## Unknown site plotted as a precise centroid marker

**Status:** rejected.

**Reason:** an arbitrary point visually implies more localization than the evidence supports. Unknown sites should be represented as regions/search areas.

## Fixed architecture of exactly three Exodus routes

**Status:** rejected.

**Reason:** the software should support the serious reconstructions retained by evidence review rather than encoding a predetermined count.
