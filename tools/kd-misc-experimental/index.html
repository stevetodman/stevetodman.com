Evidence Workbench

Organizes source-locked discriminating and non-discriminating evidence without producing a diagnosis, score, probability, treatment recommendation, or disposition recommendation.

NOT VALIDATED FOR DIAGNOSIS OR TREATMENT. Use as an evidence-organizing aid only. Missing data remain unknown. Findings associated with one syndrome do not exclude the other.

Privacy: do not enter identifiers. This page has no patient free-text field, does not save entered state, and does not transmit case inputs.

1 · Comparative phenotype

Near-exact and contemporaneous evidence

Select only findings already established from the clinical record. “No” means specifically assessed and absent; otherwise leave Unknown. A “No” is not automatically evidence for the opposite syndrome.

2 · Phenotype and surveillance context

Context kept separate from discriminatory evidence

These items orient interpretation. The application does not count KD criteria, count MIS-C organ categories, or declare that either definition is met.

Kawasaki phenotype

Rash and oral/lip changes also have near-exact Fan directional evidence; one entry updates both the phenotype context and the appropriate evidence column.

CSTE/CDC MIS-C surveillance components

Surveillance definition — not diagnostic criteria. This application displays selected components but does not determine whether the surveillance case definition is met.

Platelet <150,000/µL and ALC <1,000/µL are entered once in section 1. When present, the workbench separately shows both their Fan comparative association and their CDC surveillance context.

3 · Published-model applicability

Starnes model input availability

The published model used age, sodium, platelet count, ALT, reduced LVEF, and CRP. This workbench records input availability only and does not calculate the model result. The model requires external validation.

KIDMATCH: not reproduced here. Integration requires a verified authoritative implementation, model artifacts, preprocessing, licensing, and rejection behavior.

Interpretation boundary

  • Neither KD nor MIS-C has a single definitive diagnostic test.
  • Published group differences do not establish an individual patient diagnosis.
  • A finding associated with one syndrome does not rule out the other.
  • Unknown findings remain unknown and are never treated as normal.
  • Alternative infectious, inflammatory, toxic, and rheumatologic diagnoses still require clinical evaluation.
