Pediatric cardiologist · medical education technology

This site is a working collection of pediatric cardiology education, clinical reference tools, simulations, and family learning projects. The clinical education work emphasizes decision-making, retrieval practice, explicit uncertainty, and source provenance rather than passive slide decks.

How the site is built

Most projects are deliberately small static web applications with local assets, browser-based behavioral tests, and no account requirement. More experimental or internal work is kept separate from production-facing material.

Corrections and technical issues

Clinical content and software can both become outdated. If you find a factual error, broken interaction, accessibility problem, or stale source, report it through the repository issue tracker so the correction is reviewable and auditable.

Current visibility policy: the site is intentionally excluded from search-engine indexing for now. Direct links continue to work.
